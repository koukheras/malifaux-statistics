# Malifaux Statistics — Russia 2025–2026

Открытый архив обезличенных источников исследования турнирной активности Malifaux в России.

Публичные материалы: таблица проведённых событий Longshanks без имён игроков и LSID; агрегаты опроса без исходных анкет и свободных ответов; методология и ограничения.

- Срез: 13 ноября 2026 года.
- 178 проведённых мероприятий, 2 389 подтверждённых участий.
- 139 заполненных анкет в последнем зафиксированном срезе.
- В исходных приватных файлах содержатся персональные данные; их сюда не переносить.

Статическая публикация GitHub Pages: после размещения файлов включить Settings → Pages → Deploy from a branch → main / (root).

**Не добавлять** сюда исходную Google-таблицу опроса, поимённые турниры, LSID, сырые комментарии или внутренние Confluence-страницы.
